# 桌面便签应用调研报告

> 调研时间：2026年3月3日
> 调研人：二哈

---

## 一、概述

桌面便签应用是用户在电脑桌面上快速记录、查看临时信息的工具软件。本文调研了主流桌面便签应用的功能特性、技术架构及用户需求，为后续开发提供参考。

---

## 二、主流产品分析

### 2.1 Windows 平台

#### 1. Microsoft Sticky Notes（微软便签）
- **平台**：Windows 10/11 内置
- **特点**：
  - 系统自带，无需额外安装
  - 支持同步到微软账户
  - 支持深色/浅色主题
  - 支持手写输入（触屏设备）
  - 与 Outlook、OneNote 集成
- **缺点**：功能相对简单，自定义选项少

#### 2. Simple Sticky Notes
- **平台**：Windows
- **特点**：
  - 轻量级，启动快
  - 支持富文本格式
  - 支持提醒功能
  - 支持便签分组
  - 支持备份/恢复
- **缺点**：仅支持 Windows，无跨平台同步

### 2.2 macOS 平台

#### 1. Apple Notes（备忘录）
- **平台**：macOS / iOS
- **特点**：
  - 苹果生态深度集成
  - iCloud 同步
  - 支持手写、扫描文档
  - 支持文件夹分类
  - 支持协作共享
- **缺点**：仅限苹果生态

#### 2. Stickies（经典便签）
- **平台**：macOS 内置
- **特点**：
  - 系统自带
  - 简单直接
  - 支持半透明效果
- **缺点**：无同步功能，功能有限

### 2.3 跨平台产品

#### 1. Google Keep
- **平台**：Web / Android / iOS / Chrome
- **特点**：
  - 完全免费
  - 跨平台同步
  - 支持语音笔记
  - 支持图片识别文字（OCR）
  - 支持标签分类
  - 支持提醒
  - 支持协作
- **缺点**：需要网络同步，国内访问受限

#### 2. Notion
- **平台**：Web / Windows / macOS / Linux / 移动端
- **特点**：
  - 功能强大，不仅是便签
  - 支持数据库、看板等高级功能
  - 丰富的模板
  - 协作功能强大
  - API 开放
- **缺点**：学习成本高，资源占用较大

#### 3. Joplin
- **平台**：全平台 + 终端
- **特点**：
  - 开源免费
  - 支持 Markdown
  - 端到端加密
  - 支持多种云同步（Dropbox、OneDrive、WebDAV等）
  - 支持插件扩展
  - 支持命令行操作
- **缺点**：UI 相对简陋

#### 4. Obsidian
- **平台**：Windows / macOS / Linux / 移动端
- **特点**：
  - 本地优先，数据自主
  - Markdown 原生支持
  - 双向链接
  - 丰富的插件生态
  - 知识图谱可视化
- **缺点**：移动端需付费，同步方案需自己配置

#### 5. Simplenote
- **平台**：全平台
- **特点**：
  - 极简设计
  - 自动同步
  - 版本历史
  - 支持标签
  - 免费无广告
- **缺点**：功能过于简单，不支持富文本

### 2.4 Linux 平台

#### 1. GNotes / GNOME Notes
- **特点**：GNOME 桌面环境自带
- **缺点**：功能简单

#### 2. Tomboy Notes
- **特点**：
  - 老牌 Linux 便签
  - 支持插件
  - 支持同步
- **缺点**：维护不活跃

#### 3. xNotes
- **特点**：轻量级桌面便签
- **缺点**：功能有限

## 四、技术架构参考

### 4.1 桌面应用技术选型

| 技术栈 | 优点 | 缺点 | 代表产品 |
|--------|------|------|----------|
| Electron | 跨平台、开发快 | 资源占用大 | Obsidian, Notion |
| Qt (C++/PyQt) | 性能好、原生体验 | 开发周期长 | Joplin |
| Tauri | 轻量、性能好 | 生态较新 | 部分新兴应用 |
| Flutter | 跨平台统一UI | 桌面支持相对新 | - |
| 原生 (Swift/Kotlin/C#) | 性能最佳 | 无法跨平台 | Apple Notes |

### 4.2 同步方案

| 方案 | 优点 | 缺点 |
|------|------|------|
| 自建云服务 | 完全可控 | 运维成本高 |
| 第三方云存储 (WebDAV/S3) | 低成本 | 依赖第三方 |
| P2P 同步 | 去中心化 | 实现复杂 |
| 本地优先+可选云同步 | 灵活性高 | 需要多种方案支持 |

## 五、用户需求分析

### 5.1 个人用户
- 快速记录灵感、待办事项
- 桌面常驻，随时可见
- 简单易用，学习成本低
- 多设备同步

### 5.2 企业/团队用户
- 协作共享
- 权限管理
- 数据安全
- 与其他工具集成

### 5.3 程序员/知识工作者
- Markdown 支持
- 代码高亮
- 本地数据存储
- 命令行支持
- 可扩展/可定制

## 六、差异化机会

1. **国产化替代**：适配国产操作系统（UOS、Kylin等）
2. **AI 增强**：智能总结、自动分类、语义搜索
3. **隐私优先**：本地存储、端到端加密、无云依赖选项
4. **开发者友好**：CLI 支持、API 开放、插件系统
5. **轻量高性能**：相比 Electron 方案更省资源
6. **深度系统集成**：与桌面环境深度整合

---

## 七、建议

如果目标是开发一款桌面便签应用，建议：

1. **技术选型**：Qt (C++/PyQt) - 性能好，跨平台，适合国产系统适配
2. **核心定位**：轻量、快速、本地优先
3. **MVP 功能**：
   - 创建/编辑/删除便签
   - 富文本支持
   - 置顶、颜色分类
   - 搜索
   - 本地存储
4. **后续迭代**：
   - 同步功能
   - Markdown 支持
   - 提醒功能
   - AI 辅助
