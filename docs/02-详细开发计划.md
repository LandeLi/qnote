### 3.2 表结构详细设计

#### notes 表
```sql
CREATE TABLE notes (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    uuid TEXT UNIQUE NOT NULL,           -- UUID for sync
    title TEXT DEFAULT '',               -- 标题
    content TEXT DEFAULT '',             -- 内容（纯文本/HTML/Markdown）
    content_type TEXT DEFAULT 'plain',   -- plain/html/markdown
    color TEXT DEFAULT '#FFFFFF',        -- 背景色
    is_pinned INTEGER DEFAULT 0,         -- 是否置顶
    is_deleted INTEGER DEFAULT 0,        -- 软删除标记
    group_id INTEGER,                    -- 分组ID（可选）
    created_at INTEGER NOT NULL,         -- 创建时间戳
    updated_at INTEGER NOT NULL,         -- 更新时间戳
    deleted_at INTEGER,                  -- 删除时间戳
    version INTEGER DEFAULT 1            -- 版本号（同步用）
);

CREATE INDEX idx_notes_created ON notes(created_at);
CREATE INDEX idx_notes_updated ON notes(updated_at);
CREATE INDEX idx_notes_pinned ON notes(is_pinned);
CREATE INDEX idx_notes_deleted ON notes(is_deleted);
```

#### tags 表
```sql
CREATE TABLE tags (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    name TEXT UNIQUE NOT NULL,
    color TEXT DEFAULT '#3498db',
    created_at INTEGER NOT NULL
);
```

#### note_tags 关联表
```sql
CREATE TABLE note_tags (
    note_id INTEGER NOT NULL,
    tag_id INTEGER NOT NULL,
    created_at INTEGER NOT NULL,
    PRIMARY KEY (note_id, tag_id),
    FOREIGN KEY (note_id) REFERENCES notes(id) ON DELETE CASCADE,
    FOREIGN KEY (tag_id) REFERENCES tags(id) ON DELETE CASCADE
);
```

#### reminders 表
```sql
CREATE TABLE reminders (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    note_id INTEGER NOT NULL,
    remind_at INTEGER NOT NULL,          -- 提醒时间戳
    repeat_type TEXT DEFAULT 'none',     -- none/daily/weekly/monthly
    is_done INTEGER DEFAULT 0,
    created_at INTEGER NOT NULL,
    FOREIGN KEY (note_id) REFERENCES notes(id) ON DELETE CASCADE
);

CREATE INDEX idx_reminders_time ON reminders(remind_at);
```

#### note_history 历史版本表
```sql
CREATE TABLE note_history (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    note_id INTEGER NOT NULL,
    content TEXT NOT NULL,
    created_at INTEGER NOT NULL,
    FOREIGN KEY (note_id) REFERENCES notes(id) ON DELETE CASCADE
);
```

#### groups 分组表
```sql
CREATE TABLE groups (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    name TEXT NOT NULL,
    color TEXT DEFAULT '#95a5a6',
    sort_order INTEGER DEFAULT 0,
    created_at INTEGER NOT NULL
);
```

#### config 配置表
```sql
CREATE TABLE config (
    key TEXT PRIMARY KEY,
    value TEXT,
    updated_at INTEGER NOT NULL
);
```

## 七、Markdown 技术选型

### 7.1 Markdown 解析库对比

| 库 | 语言 | 性能 | 特点 | 推荐度 |
|------|------|------|------|--------|
| **md4c** | C | 极快 | 轻量、无依赖、CommonMark兼容 | ⭐⭐⭐⭐⭐ |
| Discount | C | 快 | 功能丰富、稳定 | ⭐⭐⭐⭐ |
| cmark | C | 快 | GitHub官方、CommonMark标准 | ⭐⭐⭐⭐ |
| hoedown | C | 快 | Sundown分支、安全 | ⭐⭐⭐ |
| Qt Markdown | C++/Qt | 中 | Qt原生、集成简单 | ⭐⭐⭐ |

**推荐：md4c**
- 纯C实现，无外部依赖
- 支持CommonMark + GFM (GitHub Flavored Markdown)
- 解析速度快，内存占用低
- 易于集成到CMake项目

### 7.2 代码高亮方案

| 方案 | 优点 | 缺点 |
|------|------|------|
| highlight.js | 语言丰富、主题多 | 需要JavaScript引擎 |
| Prism | 轻量、插件多 | 需要JavaScript引擎 |
| QSyntaxHighlighter | Qt原生、无需JS | 需要自己实现语言规则 |
| KSyntaxHighlighting | KDE库、功能强大 | 依赖KDE框架 |

**推荐方案：**
- MVP阶段：QSyntaxHighlighter 实现基础高亮
- V1.0阶段：评估集成 highlight.js (通过 QWebEngineView)

### 7.3 Markdown 扩展语法支持

| 语法 | 优先级 | 实现难度 | 说明 |
|------|--------|----------|------|
| 标题 (H1-H6) | P0 | 低 | md4c原生支持 |
| 粗体/斜体 | P0 | 低 | md4c原生支持 |
| 列表 (有序/无序) | P0 | 低 | md4c原生支持 |
| 代码块 | P0 | 中 | 需配合高亮 |
| 链接/图片 | P0 | 低 | md4c原生支持 |
| 引用 | P1 | 低 | md4c原生支持 |
| 任务列表 | P1 | 中 | GFM扩展 |
| 表格 | P1 | 中 | GFM扩展 |
| 删除线 | P1 | 低 | GFM扩展 |
| 数学公式 | P2 | 高 | 需要KaTeX/MathJax |
| Mermaid图表 | P2 | 高 | 需要JS引擎 |

### 7.4 导出格式

| 格式 | 实现方式 | 优先级 |
|------|----------|--------|
| .md | 原生存储 | P0 |
| .html | md4c转换 | P0 |
| .txt | 纯文本导出 | P1 |
| .pdf | QPrinter / QWebEngine | P2 |
