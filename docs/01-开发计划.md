## 一、项目概述

### 1.1 项目名称
暂定：**QNote** / **QtNote** / **便签君**

### 1.2 项目目标
开发一款轻量、高性能、跨平台的桌面便签应用，重点适配国产操作系统（UOS、Kylin）。

### 1.3 核心定位
- 轻量快速：启动快、资源占用低
- 本地优先：数据存储在本地，可选云同步
- 简洁易用：开箱即用，学习成本低

## 二、技术选型

### 2.1 核心技术栈

| 组件 | 技术选型 | 说明 |
|------|----------|------|
| UI框架 | Qt 5.15+ / Qt 6 | 跨平台GUI框架 |
| 开发语言 | C++17 / Qt | 主方案，性能最佳 |
| 备选语言 | Python + PyQt6 | 快速原型开发 |
| 数据库 | SQLite | 本地数据存储 |
| 配置文件 | JSON / QSettings | 应用配置管理 |
| 构建工具 | CMake | 跨平台构建 |

### 2.2 可选依赖

| 组件 | 用途 |
|------|------|
| Qt Multimedia | 语音备忘录（后续） |
| Qt Network | 云同步（后续） |
| OpenSSL | 端到端加密（后续） |

### 2.3 平台支持

| 平台 | 优先级 | 说明 |
|------|--------|------|
| Linux (Kylin/UOS) | P0 | 主要目标平台 |
| Linux (Ubuntu/Debian) | P0 | 通用Linux支持 |
