**总工时：约 35 人天（5 周）**

### 1.4 并行开发路径

```
路径A: M00 → M01 → M03 → M04 → M07 → M08  (数据-业务-UI主线)
路径B: M00 → M02 → M05 → M07 → M08        (Markdown-编辑器支线)
路径C: M00 → M06 → M08                    (系统集成支线)

并行点:
- M01, M02, M06 可同时开发（都只依赖M00）
- M04, M05 可同时开发（分别依赖M01, M03 和 M02）
```

## 六、开发规范

### 6.1 代码规范

- 遵循 Qt 编码规范
- 使用 Clang-Format 格式化
- 命名：类用 PascalCase，函数用 camelCase，变量用 m_camelCase

### 6.2 Git 分支策略

```
main (稳定分支)
  │
  ├── develop (开发分支)
  │     │
  │     ├── feature/M00-project-base
  │     ├── feature/M01-data-layer
  │     ├── feature/M02-markdown-service
  │     └── ...
  │
  └── release/v0.1.0
```

### 6.3 提交规范

```
feat(M01): 实现 NoteRepository
fix(M02): 修复 Markdown 解析问题
docs: 更新开发文档
test(M01): 添加 Note 单元测试
refactor(M03): 重构 NoteManager
```

## 七、模块接口定义

### 7.1 M01 → M03 接口

```cpp
// NoteRepository 提供给 NoteManager
class NoteRepository {
public:
    Note* findById(const QString& id);
    QList<Note*> findAll(const QueryOptions& options);
    bool save(Note* note);
    bool remove(const QString& id);
};
```

### 7.2 M02 → M05 接口

```cpp
// MarkdownService 提供给 MarkdownEditor
class MarkdownService {
public:
    QString toHtml(const QString& markdown);
    QString extractTitle(const QString& markdown);
    int wordCount(const QString& markdown);
};
```

### 7.3 M03 → M04 接口

```cpp
// NoteManager 提供给 MainWindow
class NoteManager {
public:
```
